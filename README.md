# GL-Beats-Music-Sales-Analysis-SQL-Project-
Beginner SQL project analyzing music sales database using real business questions

## 📌 Project Overview
GL-Beats is a global music record startup selling music across multiple countries.  
The management team wanted insights about customer behavior, popular genres, artists, and revenue trends.

This project uses SQL to explore the database and answer real business questions.

---

## 🎯 Objectives
- Retrieve and explore data from multiple tables
- Analyze customer distribution across countries
- Identify popular genres and artists
- Calculate revenue by city
- Generate business insights using SQL

---

## 🗂 Dataset Tables Used
- Customers
- Artists
- Albums
- Tracks
- Genres
- Invoices
- Playlists

---

## 🛠 Skills & Concepts Used
- SELECT statements
- WHERE filtering
- COUNT, SUM
- GROUP BY
- ORDER BY
- DISTINCT
- BETWEEN, LIKE
- Basic business analytics using SQL

---

## 📊 Key Analysis Performed
✔ Count of customers by country  
✔ Revenue generated by each city  
✔ Popular genres and artists  
✔ Customer filtering and segmentation  
✔ Track price and duration analysis
